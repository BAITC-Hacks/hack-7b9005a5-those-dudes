## Сохранность и ограничения

Предыдущие рабочие результаты и data bundle сохранены в `runtime/before-feedback-20260923-172819/`. Пользовательские загруженные наборы не перезаписаны; для них UI показывает предупреждение о старой версии. Для применения исправленных признаков загрузите тот же Parquet заново. Старые API-кэши сохранены, но не подмешиваются к обновлённым признакам; для нового расчёта генерацию нужно явно запустить ещё раз.

Платных OpenAI-запросов при этих исправлениях не выполнялось. Сохранены проверки структуры и чисел и прежний API-контракт; качество естественно-языкового вывода всё равно требует проверки аналитиком. Нет ground truth, независимой калибровки p_continue и нагрузочного теста на миллион узлов. План масштабирования добавлен в README, но не объявлен реализованной функцией.
