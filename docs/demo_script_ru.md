# Пятиминутный сценарий демонстрации

## 0:00–0:45 — воспроизводимость

1. Запустить `python run_project.py --no-server` и показать время полного пересчёта.
2. Открыть `output/run_metadata.json`: сверка трёх входов, число строк и параметры запуска.
3. Показать, что `nodes_roles.csv` содержит ровно 2 248 строк, а `top_nodes.csv` отсортирован и содержит не менее 20 кандидатов.

## 0:45–2:15 — первый приоритет

1. Запустить `python run_project.py --skip-pipeline --skip-dashboard` и открыть вкладку «Приоритет».
2. Выбрать первую строку, перейти к узлу на схеме.
3. Прочитать числовое `why`: отдельно назвать роль, уверенность, экспозицию, структурную критичность и временные сигналы.
4. Подчеркнуть: это гипотеза для проверки аналитиком, не вывод о нарушении.

## 2:15–3:25 — цензура depth=4

1. Отфильтровать узлы `depth=4` с высокой неопределённостью.
2. Сравнить `p_continue`, `role_score` и входящий профиль выбранного узла.
3. Объяснить, почему отсутствие наблюдаемого выхода не приравнивается к terminal и какие данные нужны следующими.

## 3:25–4:15 — кластер и устойчивость

1. Переключить раскладку графа на кластеры.
2. Открыть кластер выбранного приоритетного узла: размер, seed, внутренний оборот, гипотеза назначения.
3. Показать `cluster_stability` и кривую удаления top-N; сравнить targeted и random baseline.

## 4:15–5:00 — AI-аналитик

1. Спросить: `Почему этот узел в топе?` после выбора узла либо `Покажи узлы с неопределённой terminal-ролью`.
2. Показать вызванные локальные инструменты и числовые основания ответа.
3. Уточнить, что без API работает детерминированный режим; опциональная LLM только формулирует ответ поверх тех же read-only инструментов.
