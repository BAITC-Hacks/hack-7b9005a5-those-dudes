# Локальная интеграция дизайна с main

Основа: origin/main, commit 722ddae. Рабочая копия создана отдельно от раннего
frontend-прототипа; изменения пока локальные.

## Дизайн

Яркая палитра рабочей области: фон #0b1422, панель #19283a,
граница #526d8c, текст #ffffff, действие #dfbaff, положительный поток #3cffcd.
Segoe UI/Arial без загрузки шрифтов. Роли используют бирюзовый #3cffcd,
голубой #70d7ff, янтарный #ffe373, розовый #ff91c4, фиолетовый #d7acff;
узлы без явной роли — #b9cfe5. Цвета соответствуют легенде и графикам.

Контраст: основные цвета узлов относительно фона карты — от 8,88:1;
текст основной кнопки — 10,92:1; границы полей — 5,24:1 относительно
заливки поля. Второстепенный текст на самой светлой поверхности — 6,10:1.
Активный раздел отмечен также боковой полосой, клавиатурный фокус — обводкой.
Не связанные с выбранным клиентом узлы сохраняют 60% непрозрачности.

Компоновка: компактная навигация по разделам, общий поиск gid в шапке,
карта как основное рабочее поле, фильтры слева, карточка справа.
На небольшом экране карточка открывается поверх карты с кнопкой закрытия.
Сводка сети компактна; AI-объяснения CSV находятся в разделе помощника.

Это адаптация существующего frontend main, а не второй расчёт метрик.
В отличие от раннего прототипа, роль, кластер, confidence, priority и
альтернативы поступают из текущего dashboard_data.js, привязанного к run.

## Маршруты

- / — загрузка трёх файлов через POST /api/datasets.
- /dashboard?run=default — исходный подготовленный набор.
- /dashboard?run=<run_id> — конкретный загруженный набор.
- #network, #overview, #transactions, #patterns, #analytics, #clusters,
  #ai, #data, #method — разделы панели с поддержкой обновления и Назад/Вперёд.
- /api/query — свободный локальный вопрос; /api/action — структурированные быстрые запросы.
- /api/explain-node — отдельная генерация API.
- /api/datasets/<run>/exports/results.zip?mode=contest — конкурсные CSV с 6/6/5 колонками.
- /api/datasets/<run>/exports/results.zip — расширенные CSV и готовые API-объяснения.

Новая общая тема workspace.css подключается и на /, и на /dashboard.
Дизайн не меняет алгоритмы и результаты актуального main; API-генерация сама не запускается.
Сохранены обе выгрузки, структурированные действия помощника и предупреждение
для старых расчётов. Ошибка поиска находится под общим полем в шапке и
закрывает предыдущую карточку. Старые пользовательские наборы не перезаписаны.

## Запуск этой локальной копии

```powershell
python run_project.py --skip-pipeline --skip-dashboard --port 8767
```

Для пересчёта выданных данных: python run_project.py --port 8767.
Сборщик обновляет только dashboard_data.js и не перезаписывает дизайн.
