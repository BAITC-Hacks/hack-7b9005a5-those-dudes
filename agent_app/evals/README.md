# Offline evals

`run_local.py` проверяет реальный deterministic path помощника без LLM и без
сетевых вызовов. Кейсы покрывают готовность данных, ранжирование, неопределённые
узлы, устойчивость, отсутствующий `gid`, обязательную оговорку и запрещённые
утверждения о виновности.

```powershell
python agent_app/evals/run_local.py
```

Результат сохраняется в `results/latest.json`. Для запуска нужны готовые CSV
основного pipeline; отсутствие outputs считается ошибкой подготовки, а не
успешным тестом.
